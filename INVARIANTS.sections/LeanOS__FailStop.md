# The kernel's fail-stop core: one halt latch, one authoritative state

This is the largest file in the proof, and it ties the whole kernel together. It models the kernel's "fail-stop" rule: on any fatal error (a forbidden nested interrupt, an emergency hardware signal, a corrupted return to a program, drifting device controls) the kernel latches into a permanent halt that absorbs every later event, rather than limping on in an unknown condition. Every moving part of the kernel, from programs and scheduling to memory, messages, devices, and saved program snapshots, lives in one composite state with a single authoritative set of records, and the file's central "runtime invariant" says all of those views agree. The theorems collectively guarantee that every public operation either succeeds exactly as reported, is rejected with the state left byte-for-byte unchanged, or halts the machine, and that the single global runtime invariant survives every one of these outcomes.
