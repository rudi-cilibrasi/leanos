# Clearing cached device translations before authority changes

This file introduces a finite model of the IOMMU's translation cache. Cache keys retain the device source, assignment, domain, mapping, address, and access direction, so a translation from an old lifetime cannot be mistaken for a current one. The theorems prove that scoped invalidations remove exactly the affected lookup authority while preserving the cache bound, and that an invalidated cache becomes authoritative only after a completion names the exact fresh ticket and full scope prepared from the retained pre-state. The cache is also composed with the authoritative IOMMU/frame binding so release remains blocked by a live mapping, a published cached translation, or a pending invalidation that names the old frame lifetime. These are model proofs; they do not claim that VT-d hardware or QEMU implements the protocol.
