# From byte stream to first allocated page

At boot, the firmware hands the kernel a map of which memory is usable, delivered as a stream of small chunks. The theorems in this file follow that stream through the whole pipeline: the chunks are reassembled into one immutable byte buffer, decoded, checked against the kernel's own reserved regions, and finally used to pick the kernel's first free page of memory. The centerpiece is a lockstep proof that two independent readers of the map, a rich byte-by-byte decoder used for reasoning and the simple word-at-a-time parser the kernel actually runs, walk the very same stream step for step and reach the same verdict, so the boot parser can never accept a map the rich decoder would reject, and no stage can be fed doctored intermediate results.

- `scalarAligned8_eq_richAligned8` — The boot parser and the rich decoder round a tag's size up to the next multiple of eight bytes in exactly the same way, for every size the firmware handoff can legally have.
- `successfulTagDecodeTraversal_header_advance` — Whenever the rich decoder has successfully walked a run of tags, the next tag header can be read at the current position and the cursor advances by exactly the same rounded amount the boot parser uses, even for skipped tags of awkward sizes.
- `assemble_exact_bytes` — Bookkeeping: whenever reassembling the firmware's chunks succeeds, the resulting input is exactly those chunks' bytes laid end to end, with exactly the declared length.
- `assemble_canonicalChunks` — Any properly sized and aligned byte buffer can be cut into its standard chunk sequence, and reassembling that sequence returns exactly the original bytes, for every buffer rather than only hand-picked test data.
- `run_functional` — Bookkeeping: running the whole pipeline twice on identical inputs always gives the identical outcome.
- `authorize_functional` — Bookkeeping: the stricter authorization check is likewise deterministic, giving the same outcome for the same inputs every time.
- `accepted_assembled_bytes` — Whenever the pipeline accepts, the bytes it decoded are exactly the streamed chunks laid end to end, with exactly the declared length.
- `accepted_authority_chain` — Whenever the pipeline accepts, every stage genuinely succeeded on the recorded data: decoding the memory map, applying the kernel's reservations, and allocating the first free page.
- `accepted_selection_excludes_reservations` — Whenever the pipeline accepts, the selected page of memory does not touch any region the kernel has reserved for itself.
- `accepted_selection_sound` — Whenever the pipeline accepts, the selected page lies entirely inside memory the firmware marked usable, overlaps nothing the firmware marked off-limits, sits within the range the kernel scans at boot, and avoids every checked live reservation.
- `accepted_claim_is_canonical` — Whenever the stricter authorization succeeds, the caller's claimed summary of the results is exactly the pipeline's own summary, so a doctored claim can never be accepted.
- `rejected_exposes_no_authority` — Whenever authorization rejects, it hands back no authority at all; there is nothing to extract from a rejection.
- `scalarInitialAt_active_implies_admitted` — If the production boot parser reports that it started up successfully, then all of its start-up checks on the stream's address, size, and target page must genuinely have held; the only extra fact needed is that the size fits in one machine word.
- `scalarInitialAt_of_decode` — Every successful run of the rich decoder, with an in-range target page, produces exactly the start-up state the boot parser would build.
