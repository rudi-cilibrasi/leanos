# Final Qotom PCI admission

The final checker binds the complete sixteen-function Command vector and five explicit platform premises. It is a conditional policy boundary; these proofs do not establish the hardware premises or physical DMA containment.

- `exported_one_iff` — The exported admission returns one exactly when the final Command vector is accepted and each of the five supplied platform premises equals one.
- `initial_trust_contract_one_iff` — The named initial trust contract returns one exactly for the accepted final Command vector; its five platform premises are fixed by the contract rather than supplied as runtime switches.
