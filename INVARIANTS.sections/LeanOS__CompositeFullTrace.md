# Whole runs on the full view

These theorems carry the full view over whole runs. Another program's request is invisible to the observer when the subject gate refuses it, or when it is invisible for the ordinary view and touches nothing offered to the observer: kernel entries, memory operations, scheduler operations, copying into or revoking from another program's slot, and data messages on endpoints the observer neither names nor is offered. Every other request shows the observer its full view afterwards. Two runs that start fully indistinguishable and show the observer the same events end fully indistinguishable.

- `extra_eq_of_carried` — A step that only adds history, keeps the observer's row and every pending handover, and keeps every object offered to the observer leaves its extra authority unchanged.
- `extra_eq_of_unchanged` — A step that changes no object leaves the extra authority unchanged.
- `copy_extends` — Copying a permission only adds history at the next number.
- `extra_apply_silent` — Another program's request that is invisible on the full view leaves the observer's extra authority unchanged.
- `subjectGate_silent_full` — Such a request leaves the observer's full view unchanged.
- `run_state` — Bookkeeping: the state a run produces is exactly the run of requests through the subject gate.
- `system_replaysOn` — The observer's full view of a run can be replayed from its events in any healthy state.
- `finite_trace_full` — Two runs through the subject gate that start fully indistinguishable and show the observer the same events end fully indistinguishable.
