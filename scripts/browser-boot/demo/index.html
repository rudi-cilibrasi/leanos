LeanOS in your browser

The unchanged canonical LeanOS ISO, booted in a pinned WebAssembly build of QEMU. This is emulator-tested integration evidence, not a proof of LeanOS, the browser, or the emulator.

loading the WebAssembly runtime…

LeanOS is a Phase 1 microkernel: it runs a fixed two-subject scenario, emits its versioned boot protocol, and halts with a guest debug-exit. When you see LEANOS/10 FINAL status=PASS and guest exited (status 33), the boot succeeded — the same result the native emulator validates. First load downloads a ~40 MB runtime and requires a desktop browser with cross-origin isolation (SharedArrayBuffer). Source and details: github.com/rudi-cilibrasi/leanos.
